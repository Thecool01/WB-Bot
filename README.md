# Уведомления Wildberries и Ozon

Скрипт для рабочего ноутбука с Windows PowerShell 5.1. Он проверяет необработанные отзывы WB и отправляет сводку в группу Telegram, когда появляются отзывы, о которых ещё не сообщал. В сводке указано количество отзывов. [Документация WB API по отзывам](https://dev.wildberries.ru/openapi/customer-communication#tag/feedbacks/operation/getV1Feedbacks)

## Запуск и изменение интервала

- **start-bot.cmd** — двойной щелчок запускает проверку сразу и затем каждые 15 минут. Чтобы остановить её, нажмите **Ctrl+C**.
- **Фоновый режим** — в `setup-bot.cmd` выберите **10**. После подтверждения окно меню можно закрыть. Пункт **11** останавливает фонового бота после текущей проверки, пункт **12** показывает журнал последнего запуска.
- **config.json** — откройте в Блокноте и измените число в `"IntervalMinutes": 15`. Сохраните файл и перезапустите бота. Значение `"SendEveryCheck": false` оставляет уведомления только о новых отзывах без ответа.
- **setup-bot.cmd** — меню настройки токенов, переноса и автозапуска.

Уже настроенный бот на том же компьютере использует сохранённые настройки WB и Telegram.

## Подключение Ozon

1. В Ozon Seller откройте **Настройки → API-интеграции → Seller API**. Скопируйте **Client ID** и **API-ключ** из одного кабинета. Для чтения подходит роль **Admin read-only**. Если склады находятся в разных кабинетах, подготовьте Client ID и ключ для каждого. [Создание ключа Seller API](https://dev.ozon.ru/start/301-Kak-sgenerirovat-kliuch-dlia-Seller-API/) · [Роли Seller API](https://dev.ozon.ru/start/300-Mapping-rolei-i-metodov-Seller-API/)
2. Создайте отдельного бота через [@BotFather](https://t.me/BotFather) и добавьте его в Telegram-группу. Можно использовать ту же группу, другую группу или отдельную тему в группе.
3. Остановите бота через **Ctrl+C** или пункт **11** для фонового режима. Дважды щёлкните **setup-bot.cmd**, выберите **8** и введите данные Ozon. Выберите склад Казахстана и склад России из списка. Программа покажет название, ID и адрес каждого склада, если Ozon его вернул.
4. Вставьте токен нового Telegram-бота в скрытое поле. Отправьте одноразовую команду из окна настройки в нужную группу или тему. Подтверждение придёт от бота Ozon.
5. Запустите **start-bot.cmd** один раз. Настроенные WB и Ozon работают в одном окне с общим интервалом из `config.json`. У каждого свой Telegram-бот. Для проверки доступа к Ozon без отправки уведомлений используйте пункт **9**.

Если Ozon вернул **401 на /v1/roles**, проверьте, что Client ID и ключ взяты из вкладки **Seller API** одного кабинета, ключ активен, а внешний IP рабочего компьютера разрешён, если у ключа настроен список сетей. Если `/v1/roles` прошёл, а запрос складов отклонён, проверьте наличие метода `/v2/warehouse/list` в списке методов роли. [Настройка разрешённых сетей](https://dev.ozon.ru/start/301-Kak-sgenerirovat-kliuch-dlia-Seller-API/) · [Проверка срока действия](https://dev.ozon.ru/news/784-Izmeneniia-v-srokakh-deistviia-kliuchei-Seller-API/)

Ozon сообщает о новых отправлениях в статусе «Ожидает упаковки», группируя их по складам **Казахстан** и **Россия**. В сообщениях указаны название склада и номера отправлений. Для непрочитанных сообщений покупателей приходят отдельные уведомления с кабинетом и ID чата. Если оба склада относятся к одному кабинету, чаты проверяются по кабинету целиком.

При первом запуске бот сообщает о текущих отправлениях к сборке и непрочитанных сообщениях. После подтверждения от Telegram программа запоминает их ID и время отправки уведомлений по заказам. О каждом сообщении покупателя бот уведомляет один раз.

Для FBS бот напоминает об отправлении на первой проверке, когда прошло не меньше **60 минут** с предыдущего уведомления, если оно всё ещё в статусе «Ожидает упаковки». Напоминания за одну проверку объединяются по складу. Измените `OzonOrderReminderMinutes` в `config.json` и перезапустите бота, чтобы задать другой интервал. Значение `0` отключает повторы. Для отправлений из старой истории без времени первый отсчёт начинается с первой проверки после обновления.

Ошибки доступа к заказам или чатам видны в окне программы или в журнале фонового запуска. Остальные проверки продолжаются.

## Новости WB Partners

С `"SendNews": true` бот проверяет новости портала продавцов с тем же интервалом, что и отзывы. Подходит уже настроенный токен WB любой категории. При первой успешной проверке бот сохраняет точку отсчёта и пропускает уже опубликованные новости. Дальше он присылает сводки с заголовками и ссылками на новые публикации в настроенную группу или тему. Если новостей нет, сообщений не будет. [Метод WB API для новостей](https://dev.wildberries.kg/docs/openapi/api-information#tag/newsApi/operation/getV2News)

ID последней отправленной новости сохраняется для группы и темы после подтверждения от Telegram. Бот продолжает с этого ID после перезапуска. При переезде создайте свежий файл переноса, чтобы захватить текущий ID. Чтобы отключить новости, поставьте `"SendNews": false` и перезапустите бота.

## Перенос на другой компьютер

1. На старом компьютере остановите бота через **Ctrl+C** или пункт **11** для фонового режима. Если там был включён автозапуск, отключите его пунктом **6** в `setup-bot.cmd`, чтобы две копии не отправляли уведомления в одну группу.
2. Откройте `setup-bot.cmd`, выберите **3** и задайте пароль переноса. Рядом со скриптом появится зашифрованный `wb-transfer.json` с токенами WB и Telegram, привязкой к группе и историей уведомлений. Если подключён Ozon, его ключи, получатель и история также попадут в файл.
3. Скопируйте всю папку в постоянное место на новом компьютере. Откройте `setup-bot.cmd`, выберите **4** и введите пароль переноса. На новом компьютере токены сохранятся для текущего пользователя Windows.
4. Запустите `start-bot.cmd`. После проверки файл переноса можно убрать из рабочей папки. Для повторного переноса можно создать свежий файл с актуальной историей.

## Автозапуск при входе в Windows

Войдите под тем пользователем Windows, у которого настроены боты. В `setup-bot.cmd` выберите **5**. При следующем входе бот запустится в фоне. Если автозапуск уже был настроен или папку перенесли, снова выберите **5**, чтобы обновить ярлык. Чтобы запустить фоновую проверку сразу, остановите открытое окно бота через **Ctrl+C** и выберите **10**. [Справка Microsoft об автозагрузке](https://support.microsoft.com/en-us/windows/experience/startup-boot/configure-startup-applications-in-windows)

Пункт **6** отключает будущие автозапуски, а **11** останавливает текущий фоновый процесс. Закрытие меню и блокировка экрана проверкам не мешают. Во время сна или выключения компьютера проверки приостанавливаются, при выходе из учётной записи фоновый процесс завершается.

## Создание токена в WB Partners

1. Владелец профиля открывает нужный магазин в WB Partners и переходит в **Профиль → Интеграции по API → Создать токен**.
2. На вкладке **Для интеграции вручную** выбирает **Персональный токен** и называет его, например, «Проверка отзывов на ноутбуке».
3. Отмечает только категорию **Вопросы и отзывы** и выбирает уровень доступа **Только чтение**.
4. Создаёт и копирует токен. WB показывает его один раз. Вставьте его в скрытый запрос PowerShell на рабочем ноутбуке. Срок действия токена — 180 дней.

[Инструкция WB Partners для продавцов из Казахстана](https://seller.wildberries.ru/instructions/ru/kz/material/how-to-create-update-or-delete-a-wb-api-token-kazakhstan) · [Для продавцов из России](https://seller.wildberries.ru/instructions/ru/ru/material/how-to-create-update-or-delete-a-wb-api-token)

## Подключение WB

Откройте PowerShell в папке со скриптом и выполните команду.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\wb-bot.ps1 -Mode Setup
```

Вставьте токен в приглашение и нажмите Enter. Скрипт выполнит запрос к WB, покажет счётчики и после успешной проверки сохранит зашифрованный токен в `%LOCALAPPDATA%\WB Feedback Bot\token.dpapi`. Токен сможет прочитать тот же пользователь Windows на этом ноутбуке. Для замены токена повторите команду `Setup`. Параметр `-ExecutionPolicy Bypass` действует на процесс, который запускает скрипт.

## Создание бота и подключение группы Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и задайте имя, например «Отзывы Wildberries». Придумайте свободный username, который заканчивается на `bot`, например `company_wb_feedback_bot`. Скопируйте токен из ответа BotFather.
2. Добавьте нового бота в рабочую группу через список участников. Достаточно прав обычного участника, если участники могут отправлять сообщения. Режим приватности бота оставьте включённым.
3. В том же окне PowerShell выполните команду и вставьте токен в скрытое поле.

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\wb-bot.ps1 -Mode SetupTelegram
   ```

4. В течение трёх минут отправьте **в нужную группу** команду, которую покажет PowerShell. Например, `/wb_abc123def456@company_wb_feedback_bot`. Если в группе есть темы, отправьте команду в ту тему, куда должны приходить уведомления. Скрипт получит ID группы и отправит в неё сообщение о подключении.

Токен Telegram хранится в зашифрованном виде в локальных настройках текущего пользователя Windows. Для смены группы или токена остановите `Watch`, повторите `SetupTelegram` и запустите `Watch` снова. Чтобы отдельно проверить отправку в уже настроенную группу, выполните ту же команду PowerShell с `-Mode TestTelegram`.

[Официальный гайд Telegram по созданию бота](https://core.telegram.org/bots/tutorial#obtain-your-bot-token) · [Режим приватности ботов](https://core.telegram.org/bots/features#privacy-mode)

## Запуск из PowerShell

Режим `Watch` проверяет отзывы сразу после запуска и затем с интервалом из `config.json`. Параметр `-IntervalMinutes` задаёт интервал для конкретного запуска. Результаты каждой проверки видны в PowerShell. При первой проверке для новой группы или темы бот пришлёт одну сводку по уже имеющимся необработанным отзывам, если они есть. Дальше сводка приходит при появлении отзывов без ответа, о которых ещё не сообщалось в эту группу или тему. Скрипт запоминает ID после успешной отправки и использует их при следующем запуске.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\wb-bot.ps1 -Mode Watch
```

Чтобы получать сводку **после каждой проверки**, даже когда отзывов без ответа нет, добавьте `-SendEveryCheck`. Например, для сводки каждые 15 минут остановите текущее окно `Watch` с помощью **Ctrl+C** и запустите:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\wb-bot.ps1 -Mode Watch -IntervalMinutes 15 -SendEveryCheck
```

Первая сводка придёт сразу после успешной проверки при запуске. Чтобы сменить интервал, нажмите **Ctrl+C** и запустите команду с новым числом после `-IntervalMinutes`.

Пока ноутбук бодрствует и окно открыто, проверки продолжаются. Остановка — **Ctrl+C**. Для одной проверки используйте команду ниже.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\wb-bot.ps1 -Mode Check
```

При ошибке сети или превышении лимита запросов режим `Watch` повторит проверку. Если Telegram не подтвердил отправку, отзывы, которые всё ещё ждут ответа, попадут в следующую попытку. При ошибке доступа к WB скрипт остановится и выведет код ошибки. Если срок действия токена WB истёк, создайте новый токен, выполните `Setup` и снова запустите `Watch`.
